# Отключение автомонтирования SD-карты в Ubuntu

**Не применено.** Здесь только заготовка и обоснование выбора.

## Зачем

Рабочий стол GNOME монтирует оба раздела карты в `/media/jr/`. Работе это не
мешает, реальный обрыв питания карта пережила без повреждений. Но карта является
загрузочным устройством, а не пользовательским носителем, и в файловом менеджере
ей делать нечего.

## Чем ограничена область действия

Карта сидит на отдельном контроллере SD-слота `platform-fe2c0000.mmc`. USB-носители
висят на другой шине, под правило по этому пути они не попадают. На плате три
mmc-контроллера: пустой слот eMMC, этот SD-слот и SDIO с модулем WiFi. Блочный
диск среди них один.

Флешки, внешние диски, телефоны и камеры продолжат монтироваться как раньше.

## Правило

`/etc/udev/rules.d/99-nvme-handoff-sd.rules` в **Ubuntu** на NVMe:

```
# SD-карта в слоте платы является загрузочным устройством, а не пользовательским
# носителем. Прячем её от автомонтирования рабочего стола.
# Ручной mount продолжает работать, загрузка с карты не меняется.
SUBSYSTEM=="block", ENV{ID_PATH}=="platform-fe2c0000.mmc", ENV{UDISKS_IGNORE}="1"
```

Применение без перезагрузки:

```
sudo udevadm control --reload
sudo udevadm trigger --subsystem-match=block
```

Уже смонтированные разделы останутся смонтированными до размонтирования вручную.

## Альтернативная привязка

Можно привязаться к конкретным файловым системам, а не к слоту:

```
SUBSYSTEM=="block", ENV{ID_FS_UUID}=="EFFD-D96E", ENV{UDISKS_IGNORE}="1"
SUBSYSTEM=="block", ENV{ID_FS_UUID}=="4ff94bff-4b20-4cc1-9cf6-4f898bd840e2", ENV{UDISKS_IGNORE}="1"
```

Это уже, но после переформатирования раздела идентификатор меняется и правило
молча перестаёт работать. Привязка к слоту такого не боится.

## Побочный эффект

Инструкция на карте предлагает ставить флаг через путь `/media/jr/HANDOFF/`.
После отключения автомонтирования этот путь исчезнет. Останется вариант с явным
монтированием, он в инструкции тоже описан:

```
sudo mount /dev/disk/by-label/HANDOFF /mnt && sudo touch /mnt/force-sd \
  && sudo umount /mnt && sudo reboot
```

Если правило применяется, имеет смысл заодно поставить в Ubuntu утилиту
`sd-card/usr/local/sbin/nvme-handoff`: она монтирует раздел сама и работает
одинаково в обеих системах.
